# 纹样提取与焕活

主流程：**原型图 → 提取单元 → 排列成纹 → 视觉应用**。

从用户已有成果继续，按本次请求完成实际文件。照片从选择对象与提取开始；已有单元直接排列；已有成纹直接配色、编辑或应用。不强制重复全部步骤，不停在提示词或操作建议，除非用户只要这些。

## 入口与参考路由

先看实际输入和最近选定版本，区分来源图、单元、排列参考、色板、应用参考，不能混用。用户明确的图片用途优先于文件名、水印或“看起来像实拍”的判断；实景参考不计为生成成果。仅在对象或版本确实无法确定时问一个具体问题；有合理默认值时先执行并说明。

完整任务和跨AI执行先按[输出控制](references/output-control.md)建立本次素材角色、指定成果与验收状态。按“确定母版—确定排列—逐项应用—检查交接”推进；无需每阶段等用户确认。单项任务只执行对应阶段。关键结构失败时先修正当前项，再批量应用，不用更多效果图掩盖未定稿母版。

## 执行时必须守住的关系

1. **先选提取对象。** 镂空、雕花、窗棂骨架是不同对象。团队四瓣案例提取孔洞；回折案例提取中央雕花周围的窗棂。不能全图描边就称为正确提取。
   独立单元可以是单体、短条带或多元素组合，必须界定完整边界及连接用途；不把有裁切邻件、背景线或不明边界的截图直接称为定稿单元。已有线稿属于结构输入，不冒称建筑实拍。
2. **提取允许几何整理。** 区分可见结构、舍去的材质/细节、规则化与补绘；来源、文化名称及寓意无证据则待核查。团队作品、团山对标、敦煌配色分别管理。
3. **排列规则明确。** 保留单元识别特征，记录重复尺寸、位移、错位、旋转、镜像、线面与圆角变化。角度按结构选择，不固定 45°。不凭截图编造作者操作历史。
4. **颜色与结构分开。** 只去色或换色时保持路径、单元数量、位置、比例和裁切。SVG 优先改填充/描边；位图依宿主图像工具规则编辑并逐项对照，无法严格保持时标为候选。
5. **单元、成纹、应用分版。** 应用可以裁切、拆散局部或改变疏密，保留连续母版。彩色平涂、均匀重复、黑白照片和产品样机均可使用；黑白、密度渐变、两墨及网点不是通用要求。
6. **技术与构成分别验收。** 四方连续可用散点、条纹、连缀等方式。本次窗棂参考是二维纵横连缀，不能以条带上下复制代替。提示词写“无缝”不证明接缝通过。

## 工具与完成程度

确认当前环境实际可调用的图像、矢量/设计工具和导出方式。位图编辑遵守宿主工具规则，不擅自用脚本替代。可编辑矢量的属性修改与几何构造用矢量工具或本包工具完成。PDF、幻灯片等按宿主对应格式工具制作，并渲染检查。

本包 Python 工具处理静态、可编辑 SVG：组合重复块、平铺预览、按色值换色、转轮廓线稿、静态检查、几何比较及有参照配置的接缝像素检查。`export_unit.py` 可从 PDF 兼容 AI/PDF 中按已核对的选择配置导出路径；这不是照片自动提取。`apply_pattern.py` 可将母版用于有毫米尺寸和可编辑文字的平面模板，不生成整本 VI、包装刀版或实物效果图。超出支持范围用实际设计工具，清楚标明候选、可编辑稿、样机或制作稿。

已有[四瓣真实案例](references/team-cases.md#四瓣形实际源路径与离线复现)，优先复用实际单元，规则示范单元仅供试验。完整本地链可用 `scripts/run_case.py --output <新的成果目录>`；缺少渲染工具或现场仅需源文件时加 `--vector-only`。脚本从团队已提取单元开始，按[本地工具说明](references/tool-usage.md)执行，不冒充现场照片提取。应用图必须实际看图；SVG渲染成功不代表已在比赛设备的Illustrator中打开。

需要数字交付时用 `scripts/run_delivery.py --brief <实际需求JSON> --output <新的成果目录>`，输入与字段见[需求配置](references/delivery-config.md)。按实际请求设置`deliverables`选择海报、包装、磁贴、面料；不要求未选产品的文案与尺寸，未选项不导出、不列为缺失。不提供该字段时保留完整案例入口。可替换静态SVG单元、颜色角色、排列、毫米尺寸、文案与显式品牌/载体参考。默认四瓣，另有团队真实八角及[连拱规则验证](assets/briefs/arch-delivery.json)；规则验证不冒称建筑实拍提取。版式是可编辑起点，最终仍按用户参考调整。它导出实际参考与相应实填提示词；缺实际原型或提取单元时跳过提取复现。布包等照片级效果由实际图像工具生成并审图，数字脚本不冒充产品照片。

跨环境复用先按真实能力选择入口：支持技能文件与脚本时读取本包；只有对话/生图入口时用[通用对话指令](assets/handoff/通用对话入口.txt)与本次PNG参考。不能因为脚本测试通过，就声称豆包或所有agent已实测支持。提示词只读取本次成果，不从包内暗补其他案例的纹样和标志。

磁贴配置区分完整单元自由摆放与四块拼回同一图案；后者导出四枚、无间隙组合图、拆分图和母版还原检查。`presentation=flat`输出平面复现提示词，`product`用于照片级候选，不用冰箱门摄影提示词替代平面任务。包装交付包括正面与四面展开概念，假设深度写入记录，不称生产刀版。`scripts/delivery_audit.py --case <成果目录>`按指定范围核对实际文件、几何、尺寸、参考指纹与可执行检查；自动检查失败时脚本返回失败并保留问题记录，人工审图、来源与豆包复现仍单独验收。

外部工具不可用时先完成可独立执行的部分并说明剩余项。同一关键结构连续两次生成仍偏离时，返回选定母版或人工矢量定稿；用户要求更多探索时遵从用户。不得自动安装到其他位置、购买服务、上传或发布作品。

## 默认交付

- 单独提取、去色或局部编辑：交付对应文件和关键变化，不强制全部应用。
- 完整流程：原型/提取对照、独立单元、成纹及参数、配色或线稿、指定海报/包装/产品应用、检查记录及[跨AI提示词包](references/portable-prompts.md)。数量和载体按用户需求；以[视觉交付](references/deliverables.md)检查成果关系。
- 提示词填写本次实际母版、色值、构图、尺寸与准确文案，配上真实参考图，不只给占位模板。跨AI复现同一设计方向与构成，不保证相同像素或路径；精确结构以母版为准。
- 优先可编辑源文件与检查过的预览。嵌入 PNG 的 SVG 不算可编辑纹样路径；仅有 PNG 如实标为位图。
- 只对完成的检查写通过。样机不等于生产稿；制作包装需核对刀版和工艺。五分钟仅可描述实际计时过的审核单元选择、调参数和数字稿导出流程。

完成后展示主要成果、链接实际文件，简述变化、验证及仍需人工定稿部分。回复和案例说明使用中文。
