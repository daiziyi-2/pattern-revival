# 成纹到视觉应用

使用选定纹样与品牌资料，确定载体、尺寸、文案和用途。已有成纹直接复用。尺寸缺失可按明确假设先做概念；生产包装先取得实际刀版和工艺。

## VI 手册

组织原型对照、单元、排列、颜色、组合和应用说明，按要求制作指定页或完整手册，不固定页数。提取页讲选区与整理；排列页给单元和重复块；应用页说明用法。

最小尺寸、线宽、裁切、照片/主题组合应有实际测试，不凭空套统一 32px 或留白比例。交付真实可编辑页面与检查过的展示 PDF；仅有位图则标明。

## 海报

先安排标题及必要时间/地点/品牌信息，再定焦点和顺序。团队可用黑白建筑照片、鲜明色块、几何纹样和动物主题。纹样可为主体、背景、边饰、蒙版或拆散模块；密度变化只作用应用副本。

不只贴满底纹而忽略信息；查中文、英文、年份、品牌拼写，不发明活动事实。遮挡文字时调层级，生成错字在源文件修正。

## 包装

概念先定品类、假设尺寸与图形角色。正面安排品牌/产品名，侧面安排节奏，背面保留必要信息。真实刀版核对折线、粘口、开窗、跨面连续和裁切，刀版线独立留层。

交付展开设计、可编辑稿及效果图。未核对刀版、条码/必要信息和供应商参数时称概念或设计稿，不称可直接生产。出血、色彩和线宽按实际工艺。

## 文创与样机

磁贴分可拆单元；书签/腰封适配窄长载体；杯垫/印章查实际尺寸的线宽与间隙。容器外形与纹样分文件。

平面稿优先结构准确，产品样机可模拟材质与场景，标明样机；用户选择反光、3D 或材质效果时不套通用禁止清单。

最终核对尺寸、比例、配色、裁切/折叠、必要文案、字体和图片可用性、母版追溯；按格式渲染检查，不以文件存在替代版面检查。

用户已给品牌包装与布包照片时，提炼前者的大色块、主题图形和文字层级，以及后者的布袋外形、材质、褶皱、印花尺度。保持载体参照与纹样母版的用途分开。完整图像成果按[视觉交付](deliverables.md)检查，附[跨AI提示词包](portable-prompts.md)，便于用户在其他图像工具继续做同方向效果。

包内已提供四瓣案例的A3海报与240×80mm腰封平面概念模板，调用方式见[本地工具](tool-usage.md#有尺寸的应用与完整案例)。模板参数与文字均可修改，纹样直接引用连续母版。海报尺寸和包装尺寸均为本次概念假设；腰封不替代实际包装刀版或产品效果图。应用SVG含可编辑文字，需核对目标设备字体。
