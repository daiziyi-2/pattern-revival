# 检查与过程记录

| 阶段 | 必查 | 不能据此推定 |
|---|---|---|
| 提取 | 选区、特征、补绘、独立单元 | 文化与地理来源已证实 |
| 重构 | 原型关系、参数、对照 | 结果图说明真实操作历史 |
| 连续 | 重复块、参数、3×3、接缝与构成分别检查 | “无缝”提示证明通过 |
| 编辑 | 目标版本、几何、颜色、线条与裁切 | 生成式修改完全不变 |
| 应用 | 尺寸、字图、折叠/裁切、信息、预览 | 样机等于制造证明 |

SVG 查真实路径/图形及 image/外部依赖；嵌入 PNG 仍是位图。inspect 是静态检查，compare 是几何比较，不证明审美或接缝。制作另查工艺参数。未做的检查写“未检查”，问题写“需修正”，不默认全部通过。

文件按“案例-阶段-v版本-用途”命名，单元/成纹母版不随应用覆盖。只交付本次所需；脚本默认不覆盖已有输出。

过程记：输入及选区、来源状态、目标、输出身份、结构版本、排列参数、颜色映射、工具、实际操作、人工修订、检查结果。工具 *.record.json 是操作凭证，不自动等于人工验收。

可简记：案例=回折窗棂；输入=单元v1；操作=排列；输出=成纹v2；身份=可编辑稿；来源关系=已核对；接缝=未检查；实际尺寸=未检查。

五分钟目标仅针对审核单元选择、参数修改、模板应用与数字导出，实测后表述。不编造效率、用户测试或现场记录。
