# 配色与局部编辑

使用指定或最近明确选定版本，区分色板与纹样。四瓣的轮廓带、内孔与背景分别赋色；回折区分通道与负形；八角区分双框、交叉/节点和背景。不平均分配所有颜色。

系列沿用[VI 标注色板](../assets/palettes/zhu-garden.json)，先核对实际源文件。敦煌参考仅用户选用时试配，不作为纹样来源。精确 HEX 用属性修改，生成颜色需核对。

换色保持 d、points、坐标、transform、数量、比例、裁切及重复尺寸；不借用色板花纹，不自动加渐变。去色默认白底黑轮廓，去彩色填充，双轮廓保留，不做含灰块的灰度图。中心单线与双轮廓是不同交付，不默认互换。

改线宽只改描边并查间隙；填色路径形成的轮廓带没有独立 stroke-width，改带宽需要改路径并另存版本。用户要透明时不加背景，区分透明孔洞和白色实心。

可编辑 SVG 可用[工具](tool-usage.md)的 paint、lineart、compare。CSS 样式表、渐变、滤镜、遮罩、位图不在工具支持范围，先在实际设计软件整理或转适合工具，不伪称已转换。

位图编辑依宿主图像工具规则，检查单元形状、数量、节点、排列与裁切。改变结构则标候选并返回母版。保存颜色映射和版本关系。几何签名一致只证明几何数据未变，不证明颜色、印刷或所有视觉问题已解决。
