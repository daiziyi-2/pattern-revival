# 几何整理与系列造型

造型服务于原型、已有成稿和应用，不预设黑白或密度渐变。

团队几何层保持四瓣、回折、八角各自识别特征：四瓣保留四向轮廓和凹口；回折保留阶梯及通道，圆角变化另存版本；八角保留双框、交叉和节点，保持比例及间距。

动物层保持鹿、鹤、马、麒麟等选定姿态、卷曲装饰和内部镂空，不统一压成通用剪影。要精确复用就使用已有母版。完整案例见[团队参照](team-cases.md)。

| 目标 | 路线 |
|---|---|
| 忠实线稿 | 保留可见结构，规范线条，标注补绘 |
| 现代几何 | 舍去材质和次要细节，记录比例/对称/转折整理 |
| 装饰图形 | 保留姿态和特征，控制内部装饰密度 |
| 连续纹样 | 单元与重复规则共同设计，不自动加花蕊或中心圆 |

均匀、错位、留白、密度变化均按用途选择。32px 只用于图标辨识试验；产品按实际尺寸检查。失去来源特征时回到选定轮廓与连接，不加无关装饰补救。连缀变孤立散点时查周期与节点。
