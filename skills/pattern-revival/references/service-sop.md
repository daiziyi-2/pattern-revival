# 可复用定制服务 SOP

用于现场互动或景区经营者复用。输入为已审核单元与颜色库时，可先做数字稿；未知照片增加提取和文化核对环节。

1. 用户选单元、配色、载体及必要文字。把选择写进brief；未核实的文化寓意不作为销售描述。
2. 读取对应母版，改色与应用副本，保留来源和版本关系。模块磁贴允许用户选、换、拼单枚；组合不覆盖原单元。
3. 展示连续纹样和载体预览。用户确认图形、文案、颜色及实物条件；记录真实反馈，不填造用户测试。
4. 导出选定PNG预览、SVG设计稿、完整提示词与参考图包。其他AI使用相同母版与成稿参照；在可编辑稿纠正文字、连接和局部图形。
5. 数字交付后进入相应实物制程；按供应商模板准备磁贴、陶器、印章或包装，不把生成照片当成品。

从用户选元素开始计时，至数字稿确认导出停止；若宣传“拿到成品”则一直计到实物交付，并单列排队、设备与人工时间。五分钟是比赛目标，必须实测才能报告达成。

交接保留：订单选择、母版ID、用途/授权状态、尺寸、文案、色值、PNG/SVG、提示词包、工艺待核项、反馈与实际耗时。迁移其他景区时替换有依据的基因库与品牌资料，不复用朱家花园名称或未经核实的寓意。
