# 原型到提取单元

先利用选区、箭头或已提供成果确定对象。只有对象不清会导致明显返工时才询问。多母题可拆主纹、辅纹、开光和骨架，按用途选取。

| 对象 | 提取 | 不误取 |
|---|---|---|
| 镂空/孔洞 | 负形边界、四瓣/圆/多边形轮廓 | 不自动加花蕊与叶片 |
| 窗棂/骨架 | 转折、交叉、双线带宽、连接关系 | 中央雕花、木纹、阴影边缘 |
| 花鸟瑞兽 | 选定姿态、轮廓、识别特征、必要内部装饰 | 背景、无关枝蔓、破损纹理 |
| 开光框 | 内外轮廓、比例和转折 | 不自动加入全部框内物象 |

记录原图局部与对象；倾斜、遮挡和低分辨率影响哪些结构要说清楚。先描主要轮廓再加必要内部结构，区分双轮廓与中心单线。去材质、规则化对称/线宽/比例/圆角时标明变化，不固定删到三部件。

补绘须有相邻重复或对称依据，并标注推测；无依据时保留未确定项。交付与原图并置或叠加核对的独立单元。位图候选需要可编辑稿时，再描成真实路径。

独立单元可以是完整单体、短条带或组合，不要求一律拆到一个拱/一片瓣。必须明确可复用边界、连接端及用途；清理无关背景横线、邻件裁切残留，不能把一张局部截图直接当定稿。用户提供线稿时按线稿整理，未见原型照片就不宣称照片提取准确或已经文化溯源。

团队三组：四瓣提取窗格孔洞；回折提取中央花饰周围窗棂；八角保留双框并用交叉线与方节点整理内部。参照[团队案例](team-cases.md)，原物雕花与几何重构分别说明。

结构卡简记：源文件/选区、来源状态、对象、保留特征、舍去内容、几何整理、补绘依据、输出版本。寓意未核查不阻塞形态工作；不要将他人绘制成果称为团队实拍。

若已有PDF兼容AI中的准确提取路径，先复用而不重做照片描摹。本包的 `export_unit.py` 只读取由人工核对过的页码、路径索引与文件指纹，保留有效裁切；见[路径导出](tool-usage.md#真实路径重新导出)。四瓣案例的实际提取路径已打包，与粗描边成纹版分开保存。
