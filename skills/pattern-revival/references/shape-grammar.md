# 单元与排列的参数规则

以下是本技能操作名称，不与某论文的 R 编号强行对应，也不将几何操作赋予未经证实的文化寓意。

| 操作 | 参数 | 核对 |
|---|---|---|
| 平移 | dx、dy、单位 | 间距及连接点 |
| 行列错位 | 行距、列距、错位量、周期 | 复合块包含完整周期 |
| 镜像 | 水平/垂直、轴位置 | 方向与接点 |
| 旋转 | 角度、中心 | 按结构选角度，不固定 45° |
| 缩放 | 等比系数；非等比要说明 | 不无意拉扁单元 |
| 线宽/圆角 | 宽度、半径、端点与连接 | 间隙闭合及节点挤压 |
| 线面转换 | 描边、带状轮廓、实心或镂空 | 双框间填色不等于填满内孔 |
| 共享边/连接 | 接点、共享路径、块范围 | 断线、重边与局部线宽翻倍 |

先固定识别特征，再选择操作。连续排列见[重复块规则](repeat-patterns.md)。配色只改属性；圆角、比例和连接变化另存结构版本。

密度渐变仅按需求：记录尺寸、缺席或间距规律，随机变化记录种子。连缀母版不可随意缩小/删除节点，优先在应用副本中处理。单向渐变长图与无缝重复块分别交付。
