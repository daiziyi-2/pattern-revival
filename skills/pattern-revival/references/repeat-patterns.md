# 单元到排列

二方条带沿一个方向；四方连续上下左右重复，可散点、条纹、连缀或叠合，并不都要求互相连接。团队回折目标为二维纵横连缀，不能只把横条上下复制。

1. 确定单元版本及识别特征，选择网格和构成。
2. 四瓣按错位参照；回折关注通道；八角关注节点。先定位连接与负形，再整理线面/圆角，结构变化另存版本。
3. 定义完整重复块。半错位可把两行合为矩形块，平移复合块恢复完整周期；不必方形。
4. 穿出边界的图形按周期复制到对边再裁切，注意描边、斜线、四角和节点。
5. 保存独立块，输出至少 3×3 平铺及边界检查副本。

已有 SVG 用[本地工具](tool-usage.md)组合。周期包裹算法不判断单元选取、连接审美或通道设计。

技术检查：相邻块和四块交汇处无不需要的断线、重线、错位、颜色跳变；连缀线宽一致。像素首末列不必相同，要看实际接缝。预览成功不等于接缝已人工检查。

构成检查：保留原型关系，正负形可读，密度适用；不出现偏离目标的横条分割或空白通道。散点留白和窗棂连缀按不同目标验收。

单向密度渐变作为应用长图交付；周期渐变需明确回到起点的规则并单独检查。

有同版本配置时可运行[接缝像素检查](tool-usage.md#接缝像素检查)，将平铺与不在内部边界裁切的周期参照比较。渲染容差、实际差值和未检查项随报告保留；通过仅表示参照一致，不能代替构成和实际软件查看。分块背景可能产生抗锯齿细线，本工具的平铺和应用共用整幅背景，单块文件仍保留背景供独立使用。
